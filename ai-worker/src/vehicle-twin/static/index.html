เลือกโหมด + calibrate

คลิก 4 จุด ตามลำดับ 1→2→3→4 บนพื้นถนนที่รู้ระยะจริง แล้วกรอกพิกัดจริงหน่วย เมตร ทางขวา — ได้ตำแหน่งจริงทุกคัน (Digital Twin เต็ม)

คลิก 2 จุด เพื่อวางเส้น A แล้วเส้น B (ขวางแนวรถวิ่ง) แล้วกรอก ระยะจริงระหว่าง 2 เส้น (เมตร) — YOLO จะนับรถ + วัดความเร็วจาก 2 เส้น ส่วนตำแหน่งรถจะจำลองลงถนน

ค่าเริ่มต้นเป็นสี่เหลี่ยม 10×20 ม. ปรับได้ตามจริง

วัดระยะจริงบนถนนระหว่างเส้น A กับ B (เส้นถนน/Google Maps) — 8–15 ม. กำลังดี

ผลลัพธ์

ส่งเข้า Digital Twin (Unity)

สตรีมผลตรวจจับตาม data-contract เข้า backend → broadcast ผ่าน WebSocket → รถวิ่งใน Unity แบบ real-time
เปิด backend (npm run dev) และ Unity (Play/WebGL) ค้างไว้ก่อนกดปุ่มนี้

⚠ วิดีโอเป็น mp4v (ไม่มี ffmpeg) เบราว์เซอร์อาจเล่นไม่ได้ — กดดาวน์โหลดเพื่อเปิดด้วยโปรแกรมเล่นวิดีโอ ติดตั้ง ffmpeg แล้วรันใหม่จะเล่นในหน้าเว็บได้
